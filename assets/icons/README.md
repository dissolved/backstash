# Backstash icons

Source: user-selected Navy + Mint concept mockup. Raster assets extracted from the concept image; not original vector artwork.
Palette: Navy #233752, Mint #7DD9B5 (visual approximation; raster mockup may vary).
Files: Backstash has transparent PNGs in sizes 16, 32, 48, 64, 96, 128, 256, 512, 1024, plus a transparent master.
Firefox uses 16, 32, and 64 px icons for the toolbar, and 48, 96, and 128 px icons for the extension listing. The test package includes only these manifest-referenced icons; the master and extra sizes remain development assets.
Note: Very small icons are scaled from raster artwork and may need a purpose-built 16px simplification.
